## Random User Cards

A small JavaScript practice project built to practice the concepts I have learned so far.

The project fetches random user data from the Random User API and displays user cards with their profile image, name, email, and randomly generated Active/Inactive status.

# Features

- Fetches random users using an API
- Displays profile image, name, and email
- Randomly generates Active/Inactive status
- Refresh button to load new users
- Loading message while fetching data
- Basic error handling

# Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- Random User API
